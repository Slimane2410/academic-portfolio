# Présentation Tesla — HTML

Ouvrir [index.html](index.html) dans un navigateur.

Cette copie de la présentation Binabik conserve les **17 premières pages**, dans leur mise en page originale. Les pages 18, 19 et 20 sont supprimées. La navigation principale s’arrête à la page 17 ; les sept annexes restent accessibles séparément.

- `→` ou espace : page suivante ; `←` : page précédente.
- `O` : vue d’ensemble des 17 pages.
- `A` : annexes ; « Back to presentation » : retour à la page principale.
- `F` : plein écran ; `Échap` : fermer le menu.

Les [notes orales](NOTES_ORALES.md) suivent le même découpage. Les médias communs restent dans les dossiers du portfolio ; conserver ce dossier dans `Presentations/Tesla`. Les polices et les médias propres au diaporama sont copiés dans `assets/`.

La présentation source est conservée dans `Presentations/presentation_interview_Binabik/diaporama_v1/presentation_html`.
