# Visuels F1 — slide 4

Fichiers fournis et numérotés par Slimane : `1.pdf` (plan, une page), `2.png` (simulation), `3.png` (usinage dans la mousse), `4.png` (voiture finale).

`1-plan.png` est le rendu de la page du PDF avec Poppler (`pdftoppm -f 1 -singlefile -scale-to 2000 -png`), sans modification du plan. Le PDF original est conservé. Les quatre visuels sont affichés entiers et dans cet ordre, sans nouvelle métrique ni attribution individuelle des étapes.
